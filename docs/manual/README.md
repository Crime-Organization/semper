# Manual de uso do SEMPER

As perguntas de quem usa o SEMPER, guardadas para virar manual e vídeos em motion graphics.

Cada pergunta tem um arquivo, sempre com as mesmas partes:

1. **Pergunta:** como ela chegou.
2. **Mensagem para o WhatsApp:** a resposta curta, pronta para colar.
3. **Instrução detalhada:** o passo a passo completo, para o manual.
4. **Roteiro do vídeo:** cena por cena, com o que aparece na tela e a narração.
5. **Para revisar:** o que precisa mudar quando o sistema mudar.

O repositório está público até dezembro de 2026. Aqui entram só exemplos inventados: **nunca** dado de cliente ou nome real de pessoa.
